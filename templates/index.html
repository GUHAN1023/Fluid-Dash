AlignGuard: Automated Adversarial Prompt Tester

🐙 View Git Repository 🌐 Open Live Demo ⚖️ Score this Project (Judges)
Executive Summary:

AlignGuard provides real-time boundary checking and automated adversarial red-teaming for autonomous LLM agents before external API or shell execution occurs.

About the Project

Modern AI agents have direct access to terminals, filesystems, and databases. AlignGuard intercepts tool calls before execution and simulates boundary attacks to confirm that commands adhere to predefined organizational policies.

// Tech Stack: TypeScript, Rust WASM validator, Docker sandboxes, OpenTelemetry
