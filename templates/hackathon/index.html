AlignGuard: Automated Adversarial Prompt Tester

🐙 View Git Repository 🌐 Open Live Demo ⚖️ Score this Project (Judges)
Executive Summary:

AlignGuard intercepts agent tool calls before external execution, validating against company security boundaries using fast WASM AST rule checking.

About the Project

Autonomous agents execute terminal commands, network requests, and database queries. AlignGuard sits in the middle, running adversarial fuzzing models to prevent prompt injections from achieving breakout.

// Built with TypeScript, Rust WASM validator, Docker sandboxes, OpenTelemetry
